# ToffeeTime v2

Updated for Toffee the Vizsla.

Changes in this version:
- New Toffee title photo and an additional home photo
- Lists page removed
- Documents and Health placed next to each other in navigation and quick actions
- Growth records support weight and optional height
- Food section includes age/weight calorie examples
- Automatic calorie calculator uses Toffee's date of birth and newest Growth weight

The calorie calculator is an initial feeding estimate. Adjust using body condition, activity, food energy density and veterinary advice.
